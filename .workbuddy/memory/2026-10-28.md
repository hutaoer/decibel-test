# 2026-10-28

## 分贝测试小程序 MVP 产品方案

- 产出：`PRD-分贝测试小程序-MVP-v1.0.md`（15 段 PRD + 技术实现附录，面向开发 Agent）
- 平台假设：微信小程序原生，MVP 无服务端、无账号、数据存本地 Storage
- 功能范围：实时测量、仪表板、能量平均 Leq/最大/最小、记录列表与详情曲线、海报分享、噪声等级参考、暴露提示、校准与设置

### 关键技术结论（已核实，微信官方文档，2026-10-28）
- 采集：`RecorderManager` + `onFrameRecorded`，`format: 'PCM'` + `frameSize`（仅 mp3/PCM 支持帧回调）
- `audioMode: 'recording'`（基础库 3.17.3+）避免 AGC/NS 破坏分贝真实性；低版本降级并提示精度受限
- 录音 `duration` 硬上限 600000 ms（10 分钟）→ 必须做「到点自动结束 + 分段续测」
- 隐私：mp 后台《用户隐私保护指引》必须先声明「访问你的麦克风」，否则报 `api scope is not declared in the privacy agreement`（上线阻塞项）
- 平均值禁止算术平均，用能量平均 `Leq = 10·log10(mean(10^(Li/10)))`

### 引用标准
- GB 3096-2008 声环境质量标准：0类 50/40、1类 55/45、2类 60/50、3类 65/55、4a 70/55、4b 70/60（昼/夜，dB(A)）
- NIOSH：85 dBA/8h，3 dB 交换率（85→8h、88→4h、91→2h、94→1h、97→30min、100→15min）

### 待办

- 成功指标目标值为建议值，待业务确认

## Demo 开发（decibel-mp/）

- 微信原生小程序，无服务端，数据存本地 Storage；项目档案见 `小程序项目档案.md`
- 页面：pages/index（测量仪表盘）、pages/records（列表）、pages/detail（详情曲线）
- 计算内核 `utils/decibel.js` 已用 node 验证：单块换算 70.00 dB、energyMean([60,80])=77.03、mergeLeq 加权合并 77.03、峰值事件 1 次 —— 均符合 PRD 验收口径
- 采集参数：`format:'PCM'` + `frameSize:1` + `duration:600000`；基础库 ≥3.17.3 时传 `audioMode:'recording'`（已做版本判断）
