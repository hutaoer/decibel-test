# 分贝测试小程序 MVP Demo

对应产品文档：上一级目录的 `PRD-分贝测试小程序-MVP-v1.0.md`。

## 运行方式

1. 打开微信开发者工具 → 导入项目 → 目录选择 `decibel-mp`
2. AppID：可用「测试号」或游客模式（`project.config.json` 中已填 `touristappid` 占位）
3. 真机预览测量功能（**模拟器不支持麦克风，必须用真机**）

## 已实现（Demo）

- 首页：半环仪表盘 + 实时数值 + 柱状波形 + 当前/平均(Leq)/最大/最小统计
- 测量控制：开始 / 暂停 / 继续 / 结束，切后台自动暂停
- 保存：结束即存本地，时长 <3 秒不保存
- 记录列表：按场景筛选、长按删除、空状态
- 记录详情：时间-分贝曲线、峰值事件、暴露剂量、改标签、转发、删除
- 校准：首页右上角调整基准 K（默认 94，输入「差值」微调，有效区间 74~114）

## 关键实现说明

| 点 | 说明 |
|---|---|
| 采集 | `RecorderManager` + `onFrameRecorded`，`format:'PCM'` + `frameSize:1`（仅 mp3/PCM 支持帧回调） |
| 关闭自动增益 | 基础库 ≥3.17.3 时传 `audioMode:'recording'`，否则自动增益会破坏分贝真实性 |
| 声级换算 | `SPL ≈ 20·log10(RMS/32768) + K`，**K 是偏移量，默认 94（满量程≈94 dB SPL），不能用个位数**，否则读数全为负 |
| 平均值 | 能量平均 `Leq = 10·log10(mean(10^(Li/10)))`，**禁止算术平均** |
| 刷新 | 10Hz，Canvas 直绘波形，不走 setData 传大数组 |
| 隐私 | 不保存音频，`onStop` 后立即删除临时文件；授权在用户点击「开始测量」后才触发 |

## 上线前必须完成

1. mp 后台《用户隐私保护指引》声明「访问你的麦克风」（保存海报还需「相册（仅写入）」），否则线上授权直接失败
2. 小程序类目与录音接口权限自查
3. 真机校准回填默认 K（当前 94 为估算值，安静室内应读到 35~45 dB、正常交谈 60~70 dB 才算合理）
